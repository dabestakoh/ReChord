# ReChord 1.9.2.3

This release focuses on safer playback, improved playlist consistency, and faster repeat listening when verified audio is already cached.

## What's New

- **More reliable Play/Pause** — audio-version switches respect the listener's current paused state, including fallback paths.
- **External playlist changes** — returning from YouTube Music checks the open playlist for added or removed songs, including changes deep in long playlists.
- **Less redundant synchronization** — a short cooldown avoids repeated full checks during rapid app switching.
- **Safer playlist refreshes** — previously cached songs remain available when a background check fails; playlist metadata and artwork can update after successful checks.
- **Clearer playlist edit errors** — failed playlist operations report a retry message rather than silently appearing to do nothing.
- **Complete FLAC cache reuse** — a verified, fully cached lossless upgrade can be replayed from disk when the source and current audio preferences still permit it. Otherwise, normal streaming fallback remains available.
- **Additional regression tests** — pause intent, cache eligibility, and playlist update behavior.

## Download & Install

Choose the APK for your device from the assets below. The universal APK works on most devices, while modern Android phones generally support the arm64-v8a APK.

ReChord Release uses package `com.music.rechord`; ReChord Preview uses `com.rechord.preview` and stores data separately. Android requires the same signing certificate for an in-place Release upgrade.

*Audio availability and FLAC cache reuse depend on connected sources, device capabilities, cache completeness, and current audio-quality settings.*
