# ReChord 1.9.2.1

First public ReChord release following the branding and playlist improvements.

## Highlights

- ReChord identity and artwork for the installed application and Home screen
- Faster opening of previously loaded playlists with background synchronization
- Improved handling of large playlist lists, date-added sorting, and playlist edits
- Fixed a momentary return to default playlist order while navigating Back
- Home and playlist scrolling refinements
- Compatible custom audio add-ons without BitChord-specific device attestation
- Updated project documentation and screenshots

## Installation

Download the APK matching your device below. The universal APK (without an architecture suffix), if present, is suitable for the broadest range of devices. Most recent Android phones use `arm64-v8a`.

**Release package:** `com.music.rechord`  
**Preview package:** `com.rechord.preview` (a separate app)

Preview and Release have separate app data. If upgrading an existing ReChord Release installation, Android requires the APK to have the same signing certificate. Do not uninstall an existing installation without backing up important local data.

Audio quality and USB output behavior depend on the hardware and streaming source. This release does not claim universal USB bit-perfect support.
