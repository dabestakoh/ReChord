# ReChord 1.9.2.8 Hotfix 1

This update keeps the app version at **1.9.2.8** and raises the Android build number to **52**.

- Reduced playback memory use on devices with smaller heaps. ReChord gives the active track priority, limits standby buffering, and releases old players before preparing replacements when the output changes.
- Deferred optional AutoMix analysis under memory pressure and limited memory held by artwork and Android Auto browsing.
- Added heap usage, player buffer sizes, and the audio route to diagnostic reports. Reports are sent when you choose **Send diagnostic report** in Settings.
- Updated the README to cover features shipped across recent releases.

Download the signed APK from this release and install it over the existing ReChord release to keep your app data. The in-app updater on build 51 compares version names and won't offer this same-version update.
