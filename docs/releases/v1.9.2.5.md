# ReChord 1.9.2.5

### Playback

- **FLAC read-ahead.** ReChord prepares eligible lossless streams for upcoming tracks so they can start in FLAC when the stream is ready.
- **Seamless Quality Upgrade.** ReChord can switch from OPUS to verified FLAC mid-track. It tries a fade when the output supports it and can switch directly if the fade is unavailable. A direct switch may cause a brief pause.
- **Clearer streaming choices.** Enabling Direct Source Stream or Seamless Quality Upgrade turns the other option off.
- **Updated audio stats.** Stats for Nerds and the Audio Fidelity display refresh after a successful handoff.

### USB DACs

- **Optional software volume.** Use the in-app slider and phone volume buttons when Direct USB has no usable hardware volume control. Software attenuation changes the audio samples.
- **Clearer volume status.** Playback settings show which volume control is active, whether Direct USB is waiting, and whether fixed-volume fallback is permitted.

### App improvements

- **True-black AMOLED theme** and improved title and lyric readability in Now Playing.
- **Bulk addon import.** Paste multiple addon URLs and see which entries were added, duplicated, or rejected.
